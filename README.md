Quando devo solicitar um novo Projeto na Esteira DEVOPS?
Você deve solicitar um novo projeto na Esteira DEVOPS quando desejar criar uma infraestrutura na esteira devops.caixa para um novo sistema ou um módulo para um sistema existente.


O que acontece quando solicito um novo projeto na Esteira DEVOPS?
Esse serviço entrega de forma automatizada o repositório, pipeline e release na esteira devops.caixa. Após finalizar a solicitação, o ambiente estará disponível para iniciar as configurações.

Observação: O sistema só estará disponível no InfraFácil após executar a primeira pipeline. Essa primeira execução irá alocar o IP/Hostname e criar a VM ou Container.


Como solicitar?
Acesse no menu lateral a opção: Ambientes ➝ Esteiras DevOps ➝ Novo Projeto.



Na primeira etapa do cadastro, informe o nome do sistema. O sistema será validado na Plataforma de Gestão CAIXA (SIPGC). Se o sistema não estiver registrado no SIPGC, não será possível prosseguir com a solicitação.

Se o sistema for validado, clique no botão “Próximo”.




A próxima etapa é o cadastro do módulo. Clique no botão “Incluir Módulo”.



Em seguida, informe apenas o nome do módulo e clique no botão “Criar Módulo”. Nesta etapa, é permitido criar vários módulos.




Será necessário configurar o módulo. Selecione o módulo e, em seguida, clique no botão “Configurar Módulo”.

Uma vez selecionada a tecnologia para seu(s) módulo(s), o InfraFácil exibirá o botão para vincular o(s) módulo(s) à solicitação.



Depois de vincular os módulos, clique no botão “PRÓXIMO”.

Para conferir as informações do novo módulo vinculado, observe o quadro de módulos. Caso as informações estejam incorretas, você poderá deletar o módulo vinculado.



Para avançar para a próxima etapa, clique no botão “PRÓXIMO”. 
A próxima etapa será a de identificação do seu grupo e comunidade. Os grupos correspondem às Squads vinculadas às áreas de negócio da CAIXA. As comunidades são os principais ramos de atuação das squads. Caso não encontre seu grupo, procure a CESTI36. Caso não localize a sua comunidade, procure a CESTI35.



Após a seleção, clique no botão “PRÓXIMO”.

O InfraFácil apresentará, na próxima etapa, o resumo da sua solicitação. Nessa fase, é importante verificar se os dados estão corretos.



Para finalizar sua solicitação, clique no botão SOLICITAR.

Assim que a solicitação for processada estará criada na esteira devops.caixa o repositório, pipeline e a release. Será exibido o link de acesso.

Para consultar todos os módulos criados para o sistema acesse o menu: Ambientes > Repositórios






E também em: Consultas > Minhas Requisições
