Ajustada a etapa “Correção Artefato Final SIIFX-CAIXINHAS-BATCH” da release SIIFX-caixinhas-batch (stage EC DES). O script deixou de usar um artefato fixo e agora consulta o maven-metadata.xml do Nexus (binario.caixa, repositório snapshots). Ele identifica a versão SNAPSHOT mais recente e o último jar publicado pelo build para essa versão, faz o download e repassa a URL para a etapa de Deploy Batch (URL_DEPLOY). Para fixar uma versão específica, basta criar na release a variável VERSAO_BATCH (Settable at release time) e informá-la ao gerar a release.
